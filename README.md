# 데이터 분석 프로젝트 포트폴리오

서울시 공공데이터를 활용한 재무/신용 리스크 분석 프로젝트 2건입니다.
두 프로젝트 모두 "어떤 재무 특성이 리스크와 관련 있는가"라는 문제의식을 공유합니다.

## 1. 20대 1인가구 금융 고위험군 분류

`가구_집계구별_생활금융_통계_수정본.ipynb`

- **목표**: 20대 1인가구의 소득 대비 소비율을 기준으로 고위험군을 정의하고, 이를 예측하는 분류 모델 구축
- **접근**: 단순 회귀 대신, 소득 대비 소비율(소비/소득)이 높을수록 상환 여력이 낮아질 것이라는 가설을 세우고 파생변수 설계 → 상위 25%를 고위험군으로 라벨링
- **모델**: RandomForest, LightGBM 비교
- **데이터 누수 발견 및 제거**: 초기 버전은 타겟(소비율) 생성에 쓰인 소득 컬럼(1인가구평균총소득)이 피처에 그대로 남아있어, accuracy 0.76이라는 겉보기 좋은 성능이 나왔습니다. 이를 발견한 뒤 라벨 생성에 관여한 컬럼과 그 구성요소(근로/사업/기타소득 절대값)를 모두 제거하고, 소득 구성 비율(근로소득비중, 사업소득비중) 등 독립적인 피처로 재구성했습니다.
- **재평가 결과**: RandomForest accuracy 0.73 / 고위험군 recall 0.08 / AUC 0.44, LightGBM accuracy 0.65 / 고위험군 recall 0.17. AUC가 랜덤 수준(0.5)에도 못 미쳐, 지역 단위 집계 피처(20대 가구수, 1인가구수, 소득 구성비, 대출잔액)만으로는 소비율 상위 25% 여부를 구분하기 어렵다는 것을 확인했습니다.
- **한계 및 해석**: 가설 자체보다는, 집계구(지역) 단위 통계로 개별 가구의 소비 패턴 차이를 포착하는 데 한계가 있는 것으로 보입니다. 가구 단위 마이크로데이터가 있다면 다른 결과가 나올 가능성이 있습니다.

## 2. 집계구별 신용대출 보유 여부 예측

`서울시데이터분석_수정본.ipynb`

- **목표**: 신용카드 이용 패턴, 소득 구성(급여소득자/자영업자 비율) 등 재무 특성으로 신용대출 보유자 비중이 높은 집계구(상위 50%)를 예측
- **타겟 재정의 과정**: 처음에는 '성별'을 타겟으로 시도했으나 accuracy가 55~58%로 랜덤 수준에 그쳐, 데이터가 실제로 담고 있는 정보(신용/대출 관련 지표)를 활용하는 방향으로 타겟을 재정의. 신용대출 보유자 수를 중앙값 기준 이진화(`대출보유_상위50%`)해 새 타겟으로 설정
- **데이터 누수 방지**: 타겟 생성에 쓰인 컬럼(신용대출 보유자 수)과 그와 직접 연동되는 파생 지표(평균 신용대출 잔액)는 피처에서 제외
- **모델링 과정**: DecisionTree, RandomForest, XGBoost 3종을 베이스라인으로 비교(validation accuracy 각 0.575 / 0.550 / 0.500) → 클래스 불균형을 고려해 RandomizedSearchCV(scoring='f1')로 DecisionTree, XGBoost 하이퍼파라미터 튜닝 → 최종 XGBoost 모델 선정
- **최종 성능**: Test accuracy 0.54, f1-score 0.48~0.59, AUC 0.54 — 다수 클래스 비율(baseline 0.54)과 거의 동일한 수준으로, 8개 재무 피처만으로는 신용대출 보유 비중을 구분하기 어렵다는 것을 확인
- **변수 중요도**: 8개 피처의 중요도가 0.122~0.131 범위로 고르게 분산되어, 특정 피처가 지배적인 신호를 갖지 않음을 보여줌
- **한계 및 해석**: 집계구 단위 데이터라 개인 신용점수·기존 부채 상태 등 실제 대출 심사에 쓰이는 핵심 정보가 빠져 있어, 간접적인 소비/소득 패턴만으로는 예측이 어려웠던 것으로 보임. AUC가 0.5에 근접한 것으로 볼 때 표본 부족보다 피처 자체의 정보 부족이 더 근본 원인으로 판단됨
